Ingeniería en Tecnologías de la Información

Esta carrera se enfoca en el diseño, desarrollo y mantenimiento de aplicaciones tecnológicas, utilizando herramientas modernas para resolver problemas en diferentes áreas.

Descripción

Este proyecto tiene como objetivo aprender el uso de Git y GitHub para el trabajo colaborativo en el desarrollo de software, aplicando buenas prácticas de control de versiones.

Objetivos

  • Aprender a utilizar Git para el control de versiones.
  • Trabajar de forma colaborativa mediante GitHub.
  • Desarrollar una página web básica utilizando HTML.

Herramientas utilizadas

  • Git
  • GitHub
  • HTML5
  • Visual Studio Code

Habilidades que se desarrollan

  1. Trabajo en equipo.
  2. Control de versiones.
  3. Desarrollo web básico.
  4. Organización de proyectos.
