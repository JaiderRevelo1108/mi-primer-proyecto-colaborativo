# Mi Primer Proyecto Colaborativo

## Objetivo del proyecto
Aprender a utilizar Git y GitHub en un entorno de desarrollo simulado.

## Integrante
- Jaider Revelo

## Herramientas colaborativas investigadas
- Git
- GitHub
- Ramas (Branches)
- Commits
- Merge
  
*Nota: Esta línea fue editada desde la rama mejoras*

## Lo que aprendí

- Aprendí a usar los commits para guardar los cambios del proyecto.
- Aprendí a crear ramas para realizar cambios sin afectar el proyecto principal.
- Entendí que GitHub permite guardar proyectos y trabajar en equipo.

## ¿Qué espero lograr?

- Organizar mejor mis proyectos.
